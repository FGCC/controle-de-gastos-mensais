# 📊 Projeto: Planilha de Controle de Finanças Pessoais

Este repositório contém um modelo prático e eficiente de planilha para gestão financeira. O objetivo é ajudar você a organizar suas contas, entender seus hábitos de consumo e planejar seu futuro financeiro.

## 🌐 Conteúdo Complementar

Para baixar outros modelos, ler guias sobre organização financeira e entender melhor sobre tributação de ações, visite o meu portal oficial:
👉 **[DARF 6015](https://www.darf6015.com.br)**

## 🚀 Recursos do Projeto

* **Gestão de Entradas e Saídas:** Registro simplificado de receitas e despesas.
* **Categorização Inteligente:** Separação por tipo de gasto (moradia, lazer, educação, etc.).

## 🤝 Como Contribuir
